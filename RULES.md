# Rules for the AI agent

1. Read docs/SRS.md, docs/ARCHITECTURE.md and docs/PROGRESS.md before each task.
2. Build ONLY the task I give you. Do not add extra features or rewrite unrelated files.
3. Never hard-code visible text. Use the translation files for English, Telugu and Hindi.
4. Every new database table must have Row Level Security enabled and policies written. Explain each policy in plain words.
5. Never put passwords, API keys or secrets in code. Use environment variables.
6. If something is mocked, fake or hard-coded, say so clearly. Never present mock data as real.
7. Never let owners set verification badges or approval status themselves.
8. Before finishing, update docs/PROGRESS.md.
9. I am a student learning while building. Explain what you did and why in simple language, and keep code easy to read with short comments.
10. If a requirement is unclear, ask me instead of guessing.
